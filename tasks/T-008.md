# T-008 — Run the app suites in CI and turn on branch protection

## Description
**Priority 4 of 9 (deploy blocker: SDET-1).** CI runs only the starter's procedure checks. None of the seven app suites (build, `test:stats`, `test:reminders`, `test:api`, t3, t4, t5) runs automatically, which crosses the hard gate "no manual-only testing". Branch protection on `main` isn't confirmed, so every gate can be bypassed. This task adds the `app (build + tests)` job drafted in `round-3-devops.md` (OPS-5), pins Node, makes the test scripts safe to run in CI, and records the branch-protection settings.

- **Planned branch:** `chore/ci-app-tests` (created when this task moves to in-review).
- **Stakeholder / DRI:** rcluff11.
- **Closes:** SDET-1 = SCOPE-7 = OPS-5; OPS-6 (branch protection); OPS-9 (Node pin); SDET-2 (check-count ratchet); SDET-3 (t4 silent skip); SDET-7 (tests follow `VITE_PB_URL`); SDET-9 (soft observations); SEC-13 (npm audit, PocketBase checksum, Dependabot alerts); OPS-13 (`.gitattributes`, executable bits). Also completes T-003 criterion 3's branch-protection step, which can only happen after T-003 merges (OPS-6 ordering).
- **Review scope (`AGENTS.md` § 5):** config/infra (Architect + DevOps) plus Test Engineer for the test list; it also edits `docs/testing.md` and `docs/deployment.md`, so all 9 agents for those files.

## Acceptance criteria
1. **The job runs and is green.** `.github/workflows/checks.yml` has the `app (build + tests)` job from `round-3-devops.md` OPS-5: actions pinned by SHA, `contents: read`, `persist-credentials: false`, no secrets, `timeout-minutes`. Its PocketBase 0.41.0 SHA-256 is filled in from the release's `checksums.txt` and cross-checked with `sha256sum` of a separate download; the PR shows both values. Check: the job passes on the PR.
2. **It fails when it should.** On a throwaway branch, a deliberately broken `test:stats` assertion and a stopped PocketBase each make the job fail. Check: links to both failing runs in the PR.
3. **t4 can't skip silently.** With `CI` or `REQUIRE_PB=1` set, a failed PocketBase health check in t4 is a failure (exit non-zero). Check: run with PocketBase stopped.
4. **Tests never hit production.** `api-test`, t3, t4 and t5 read `TEST_PB_URL` and refuse any host other than `127.0.0.1`/`localhost` unless `ALLOW_REMOTE_PB=1`. Check: running with `TEST_PB_URL=https://example.com` exits non-zero before any request.
5. **Soft observations are assertions** (t3 `:59`, t4 `:331–337`, t5 `:165`) or are removed where `test:api` already asserts them.
6. **Check-count ratchet.** CI fails if a suite's check count drops below the baseline (211 / 179 / 162 / 62 / 59 / 74) without the baseline file being changed in the same PR.
7. **Node pinned.** `netlify.toml` has `NODE_VERSION = "22"`; `package.json` has `"engines": {"node": ">=22.12"}`. Check: Netlify deploy preview log shows Node 22.
8. **Line endings and modes.** `.gitattributes` with `*.sh text eol=lf` and `.githooks/* text eol=lf`; hooks and `scripts/*.sh` committed as `100755`. Check: `git ls-files -s .githooks scripts/*.sh`.
9. **Branch protection on (owner action).** After merge, the owner applies the ruleset in `round-3-devops.md` OPS-6 (required checks including `app (build + tests)`, no bypass, Dependabot alerts on), and the date and the exact words are recorded in this task's activity log and in T-003's. Check: the activity-log lines.
10. `npm audit --omit=dev` runs as a non-blocking warning step. `docs/testing.md` § gates and `docs/deployment.md` § CI reflect the real status.

## Out of scope
- c8 coverage and a browser e2e tool: new dev dependencies need the owner's approval (T-012).
- `scripts/test/test-commit-msg.sh`'s tab-in-filename case fails on Windows only; it is expected to pass on the Linux runner. If it doesn't, that is a starter bug to report upstream, not to loosen.

## Risks / dependencies
- A required check that has never reported blocks every PR, so the ruleset is applied only after the job has reported once (OPS-6 order).
- `actions/setup-node` must be added to the allowed actions if Actions are restricted.
