### Warnings
- [ ] **FE-8** — "Today" goes stale when the PWA resumes after midnight; a tick can land on yesterday. Shared `useToday()` hook. (Frontend; `test:stats` for the date logic.)
- [ ] **FE-9** — "All tasks" mode lets you tick tasks not scheduled today, inflating completions targets. Client fix plus a server rule rejecting completions outside a task's window. (Frontend + Backend.)
- [ ] **FE-10** — `save()` drops an updated record not in local state; EnergyCheckin recovery never shows; direct `pb` call in a component. (Frontend.)
- [ ] **FE-7** — starter categories come back whenever a user has none; seed once at sign-up, ideally in a `users` create hook. (Frontend + Backend.)
- [ ] **DATA-3 = FE-12** — every completion ever made is loaded on each open and after every delete; bounded window plus local cascade patches; course bulk delete as one request. (Frontend + Data Engineer sign-off on the window.)
- [ ] **SEC-6 (hooks side) = DATA-12** — per-user record caps for `tasks`, `blocks`, `completions`. (Backend + Architect.)
- [ ] **SEC-2 option 1** — least-privilege `services` auth collection for the sender; revisit per ADR 0003 (T-009). (Backend + Architect + Data.)
- [ ] **SDET-4** — a browser e2e tool (Playwright suggested) with a golden path and an axe smoke per view. New dev dependency: needs the owner's approval. T-006 and T-007 reference this as their e2e follow-up.
- [ ] **SDET-2 (tool)** — c8 coverage over the Node suites. New dev dependency: needs the owner's approval. (The ratchet is in T-008.)
- [ ] **UX-21** — filtered To-do list can be blank or misleading. (Frontend + UX.)
- [ ] **UX-23** — no visible password rule, busy text, or "Forgot password?" (depends on whether reset email works on the VM; owner question). (Frontend + UX + Architect.)
