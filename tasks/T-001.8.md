# T-001.8 — Write `testing.md`

## Description
Test Engineer documents the testing pyramid for this project: which test types run at which level, on what tooling, with what coverage gates, and how test data is managed.

## Acceptance criteria
- [ ] `/docs/testing.md` exists.
- [ ] Documents test levels: unit, integration, contract, end-to-end, security/dependency scans.
